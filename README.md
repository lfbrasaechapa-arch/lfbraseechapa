# L&F Brasa e Chapa · Gerenciador de comandas

Site estático (HTML + JS) com dados no Supabase.

- `index.html` — o sistema inteiro (comandas, produtos, compras, fornecedores, financeiro)
- Banco: tabela `public.docs` no projeto Supabase `lf-brasa-e-chapa` (só usuários logados leem e gravam)
- Logins da equipe: criados no painel do Supabase em Authentication → Users → Add user
